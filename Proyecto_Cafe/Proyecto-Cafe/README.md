# Café Origen · Analítica v0.1

Proyecto de práctica sobre arreglos, recorridos, acumuladores, agrupaciones y rankings.

## Ejecutar con Node.js

Desde esta carpeta:

```sh
node explorar.js
node verificar.js
node depurar.js
node reporte.js
```

El módulo `analitica.js` contiene las funciones y `datos.js` el historial de muestra.
La bitácora y las trazas están en [bitacora.md](bitacora.md). También se incluye
`reporte.psc` como evidencia en PSeInt, según el formato mencionado en la guía.
